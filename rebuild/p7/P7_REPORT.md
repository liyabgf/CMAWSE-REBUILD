**1. d6v3 与 d1v2b 在独立测试中是否仍有鉴别力？** 是。两者在从未参与开发决策的 s11/s13 + 新构造上逐项复现 P6 结论：d6v3 full 判据误通过 0（12 类主体，含 6 类新主体与投机缓存探针）、三分量各有专属反例（E←wrong_map/anti_equivariant；R2←constant/tau_hash/memoizer；I←order_sensitive）；d1v2b 上平凡主体全败、rule_oracle 唯一通过（delta +0.40，b/c=12/0，p=0.00073）、144 格语义保持变换零翻转。

**2. 新指标在哪些主体或输入分布下失效？** d6v3：(a) 不测正确性——seen_correct_unseen_fail（已见对、未见错）通过，属范围而非缺陷；(b) 记忆化投机仅覆盖朴素缓存，tau 键控等变作弊理论可行（披露）；(c) 限于脚本主体族。d1v2b：(a) 限于 CONDITION_C 物理（账本可充分学习 (X,act)→Y）；(b) 限于平衡构造（中性查询必须使 X 边际出错，否则回到 d1v2 的天花板退化）；(c) oracle 优势=预编码世界物理（能力锚点的定义性事实，无标签泄漏，已审计）。

**3. 真实 LLM 接入后哪些性质由模型决定、哪些由机制决定？** **未回答——P7-B 全部 NOT_RUN**：本机无 ollama/LM Studio、无任何 API 密钥（探测记录在 LLM_CONTROLLED_EVALUATION.md）。实验设计与判定规则已冻结存档，接入后可原样执行。不以脚本主体冒充，不伪造响应。
