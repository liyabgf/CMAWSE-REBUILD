# P6-C：D1 效度重设计报告

## 已知效度威胁（P4/P5 遗产，全部正视）：账本三方平局、holdout 全 q0、平凡主体高分、结论随排列/命名翻转、置换检验缺失。

## 阶段一：预注册 d1v2（N=9 平衡 holdout，冻结判据 acc≥0.5 ∧ delta≥δ* ∧ p_adj<0.05，δ* 调参冻结）

调参集冻结 δ* = −0.3333。留出集 s5 实测：X 边际基线在 N=9 平衡集上 acc_base=1.000（平衡构造使 X 单独决定 Y），oracle delta=0、b/c=0/0、p=1.0，**所有主体（含 oracle）均不通过**——天花板退化 + 零统计功效。**判定：INSUFFICIENT**（按 P6_PLAN 冻结判据）。该失败本身证实了两点原威胁的直接后果：基线强度依赖 holdout 构造；N=9 下符号检验最小可达 p=0.5（n_disc=0 时不可检验）。

## 阶段二：事后 d1v2b（N=36，X 内 act 变化使基线系统性出错 16/36；非预注册，公开回代）

留出集 s5，acc_base=20/36：

| 主体 | acc | delta | b/c | p_raw | p_bonf | pass |
|---|---|---|---|---|---|---|
| constant_q0 | 0.556 | 0.000 | 16/16 | 1.0 | 1.0 | False |
| majority_class | 0.222 | −0.333 | 0/12 | 0.0007 | 0.004 | False |
| random | 0.417 | −0.139 | 6/11 | 0.332 | 1.0 | False |
| simple_baseline_v2 | 0.556 | 0.000 | 0/0 | 1.0 | 1.0 | False |
| learned_agent | 0.556 | 0.000 | 0/0 | 1.0 | 1.0 | False |
| **oracle** | 1.000 | +0.444 | 16/0 | 4.6e-5 | 2.8e-4 | **True** |

- 平凡主体（constant/majority/random）全部失败，且 constant 的失败由 delta 门与置换检验双重把关。
- learned_agent ≡ 基线（未见过的 (X,act) 组合回退 X 边际——预期行为，如实记录）。
- **不变性网格：3 标签重命名 × 4 账本排列 × 6 主体 = 72 格，结论翻转数 0**（D1_PERMUTATION_RESULTS.csv）——P4 的排列/命名敏感缺陷在本设计下消除（基线 X 边际无平局敏感性；oracle 判据不依赖账本顺序）。
- **阈值敏感性：δ* ∈ [0, 0.40] 全区间通过主体集恒为 {oracle}**（D1_THRESHOLD_SENSITIVITY.csv）——本设计下结论对阈值选择不敏感；阈值量级普适依据仍 UNRESOLVED（仅报告敏感性曲线，不主张 0.15 的全局合理性）。
- 置换检验：统计量 = McNemar 型不一致对差（b−c）；零假设 = 主体与基线正确性可交换；置换单位 = 逐查询对内符号；闭式二项尾（与全枚举等价，已注明）；多重比较 Bonferroni ×6；p 解释边界：仅反映本 holdout 集上的分离显著性，不外推。

## 判定

- d1v2（预注册）：INSUFFICIENT。
- d1v2b（事后修订）：在本协议上满足全部验收（平凡主体不误判、语义保持变换零翻转、oracle/无能力主体分离依据明确、置换检验真实运行可复现）。**判定：PARTIALLY_SUPPORTED**——限于 N=36 平衡构造与本主体族；未对真实 LLM 验证；外推到其他查询分布需重验。
- 与 v7 测试中的 D1（原始实现）的关系：原实现仍是 INSUFFICIENT（P4 结论不变）；d1v2b 是 REWRITTEN 新设计，不冒称恢复原始意图。
