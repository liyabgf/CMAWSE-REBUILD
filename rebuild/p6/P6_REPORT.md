## 最终报告七问

**1. D6 能否区分正确等变主体与恒定输出主体？**
原 D6 不能（恒定输出 d6=0，INVERSE_MAP 原空间直通是结构根因）。预注册 d6v2（E∧R∧I）仍不能（tau_keyed 反例）。事后修订 d6v3（E∧R2∧I，R2=标签交换响应性）能：在 s1/s5/s7 三组会话上六类主体全分离。判定：原 D6 = INSUFFICIENT；d6v3 = SUPPORTED（限脚本化主体与本协议，事后修订已披露三轮回代与一次主体修正）。

**2. 当前重放到底保证了什么？真实性验证依赖什么参照？**
现行 CLI 保证：种子派生一致性 + 以账本 action 为源的世界重执行逐字相等（内部一致性，含顺序、重复、遗漏、异结局篡改的检出）。不保证：action 真实性（同结局篡改双方同步变化）、会话-内容绑定、评估字段审计。REWRITTEN V3（事件哈希链 + 带外链根见证库）补上内容篡改检出与来源绑定；见证缺失/坏行返回 UNDETERMINED。参照自身信任假设：见证库独立可信；链不证明事件真实发生；账本+见证同时被改写则不可检出（实证）。

**3. D1 是否摆脱标签命名/排列敏感性与平凡预测问题？**
原实现：没有（P4 结论维持，INSUFFICIENT）。预注册重设计 d1v2（N=9）：天花板退化 + 零功效，INSUFFICIENT——证明"换判据不换数据"仍失败。事后 d1v2b（N=36、act 变化、X 边际基线、McNemar+Bonferroni）：平凡主体全败、oracle 唯一通过（delta +0.444, p_bonf≈3e-4）、72 格语义保持变换零翻转、阈值在 [0,0.40] 全域结论稳定。判定：PARTIALLY_SUPPORTED（限本构造）。阈值普适量级依据仍 UNRESOLVED。

**4. typecheck 是否应原生化？**
可原生但非必须：A2 外挂与 A3 原生在 24 用例语料上结果等价（零崩溃、零误拒、零非法接受、可追溯）；A3 的冻结回归验收（v7 7/7）通过。增量价值 = 校验点进入引擎记录层、覆盖置换调用、免调用方纪律；成本 = 引擎副本维护。证据支持：安全可行；证据反对强制化：无。

**5. P3–P6 后，哪些机制独立贡献有证据支持？**
SUPPORTED（有对照实验）：认知投影（潜变量不可见）、history 深拷贝（变异封禁）、解析守卫 fail-closed（结构级畸形）、world.step 非法动作拒绝、AUDIT 记录完整性、CLI 重放一致性校验、typecheck 类型边界（外挂/原生等价）、d6v3 鉴别力、d1v2b 效度（限本构造）、V3 真实性参照。PARTIALLY_SUPPORTED：D1 原始实现（测试通过≠有效）。INSUFFICIENT：原 D6、预注册 d1v2。UNVERIFIED：Branch A 证人隔离/仲裁（EXTRACTED 未执行）、Hmid 模型族。UNRESOLVED：坏行处理、会话绑定、D6/D1 原始规格意图、D4 上下文因果（BLOCKED）。

**6. 哪些性质由显式机制保证？**
确定性结构保证：投影、深拷贝、world.step 守卫、解析守卫（结构级）、类型校验（A2/A3）、哈希链完整性（信任假设内）、重放一致性。统计证据依赖：D1/D6 类能力判定（任何指标版本）。外部信任假设：见证库、真实 LLM 行为分布（未测）。

**7. 下一阶段最值得投入 / 应暂停？**
投入：d6v3/d1v2b 的对照验证移交（并入一致性测试体系，标记 REWRITTEN）；真实 LLM 主体的受控接入（需记录模型/提示/采样/次数后方可作统计主张）；Branch A 提取物的执行验证（目前 UNVERIFIED）。暂停：对原始 D1/D6 实现的进一步修补（已证不足）；对"重放=真实性"的表述；对 Schema A/B 的裁决（本轮范围外维持）。
