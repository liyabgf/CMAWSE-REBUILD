STEP 10 — H_{\text{mid-3}} 形式化实现契约全览 
Hmid3 Speci
ﬁ
cation Contract: 
  Algorithm              = Deterministic Uniform-Cost Search (BFS on AST by node count) 
  State Representation   = Tuple(AST_partial, g_cost: int, CanonString: str) 
  Start Node             = Root non-terminal "<Program>" with g=1 
  Successor Order        = Leftmost non-terminal derivation; Sorted by ASCII of CanonString 
  Cost Function          = g(n) = Total AST node count; h(n) = 0 (Deleted) 
  Goal Condition         = Complete AST and g <= 12 and Error(AST, D_train) == 0 
  Duplicate Handling     = Exact string deduplication via ClosedSet 
  ClosedSet Structure    = Set of serialized CanonString 
  Max AST Nodes Limit    = 12 
  Expansion Budget Limit = 1000 expanded nodes (Machine-independent) 
  Timeout Safety         = 500 ms (OS watchdog only; not algorithmic boundary) 
  Failure Result         = "IF X == A THEN q0 ELSE q0" 
  Output Format          = Canonical string of winning AST 
  - ABI 闭合定性：CLOSED
